# Observation agent: the project at a glance

A system that runs inside Claude Code, reads all 3,240 messages of an email archive from Enron, finds the work that recurs, prices what could be automated at the brief's $85 an hour, and ties every claim to a message and a verbatim quote. One command, `/observe`, runs it; the outputs of one real run are committed beside the code, and this site is a reading copy of both.

## The submitted run in figures

- Automatable work a month (counted + estimated): $2,231 = $526 counted email time + $1,705 estimated hands-on work. 26.3 hours a month. The estimates put it between $1,243 and $4,989. Observed in 4 mailboxes, 1999-2002.
- Messages read (counted): 3,240; 3,201 after 39 duplicates.
- Recurring processes (counted): 60; 42 seen often enough to count in the total.
- Documents drafted (counted): 5; for the opportunities above the threshold.
- Run time (measured): 29.0 min; from the run log.
- Subagents started (counted): 130; 4 fix rounds.
- Quotes exact (counted): 2,684; 13 repaired, 0 rejected.

From run `20261019T134634Z` of 19 Oct 2026. Every figure above is read from the run's output when this site is built; [the run's facts](https://schom975-coder.github.io/observation-agent-assignment/run.md#facts) has the rest.
