# Decisions: plan/architecture

- **Headline hours come from the email trail, not model estimates.** Code counts actions in each occurrence (written, read, forwarded, chased) and prices them with fixed, published per-action minutes and automatable shares, then x $85/h. Alternatives: model estimates minutes per occurrence and automation fraction (the original blueprint); hand-assigned minutes per process. Won because the brief checks whether a model holds any of the hours arithmetic, the headline must not move between reruns on the same corpus, and planted effort claims (`482.`) can't push it. Cost: it is a floor and undercounts off-email work; the model's off-email estimate is shown beside each opportunity, labelled, never added in.
- **TypeScript on Node >= 22.18, zero runtime deps.** Alternative: Python 3.11 stdlib (better built-in email and date parsing). Won because hooks need one interpreter name on every OS (`node`; Python is `python3` on macOS and `python` on Windows), one language spans pipeline, hooks and dashboard, and Scott reads TypeScript daily. Install burden was explicitly not a factor. Consequence: strict hand-rolled date parser, never `new Date(string)`.
- **Extractor subagents on `sonnet`.** Alternative: inherit the session model. Won because extraction is tagging and quoting across ~75 calls, the quote validator catches errors, and it conserves the subscription window; synthesis keeps the stronger session model. Revisit if M3 shows poor tagging.
- **Artifact threshold: tier A/B, top 8 by automatable $/mo, at least 3; dollar bar set after the first full run.** Alternative: fix $1,000/mo now. Won because with 4 mailboxes the real figures are unknown and a bar chosen blind may filter nothing or everything; the chosen bar gets defended in NOTES.
- **Dollar scope: observed in 4 mailboxes, labelled.** Alternative: extrapolate to the company. Won because an extrapolated figure is invented; a president-facing number has to survive "how do you know?". Extrapolation logged as next-week work.
- **Commit model outputs (extractions, taxonomy, synthesis); don't commit batch files.** Alternative: commit nothing, reviewer runs cold. Won because the brief requires one real run's output and "don't repeat finished work"; README explains the warm rerun and `--force`.
- **Injection message shown as a flagged finding with citation.** Alternative: handle silently. Won because surfacing it shows the defence works and the brief asks us to cite everything.
- **Taxonomy generated once by the model, cached, then reviewed by us.** Alternative: hand-written list. Won because the brief says the system identifies the processes; a hand-written list would mean we did. Extractors can propose new keys.
- **Personal/noise mail classified, excluded from processes, counted on the dashboard.** Proves every message was read without inventing processes from chatter.
- **Headline total = tiers A+B; "including low-confidence" shown beside it.**
- **Orchestration: `/observe` skill fans out subagents from a code-kept queue; M3 is a go/no-go gate.** Alternative: a script spawning `claude -p` workers, kept only as a last resort because it weakens "runs inside Claude Code".
- **Corpus guard enforced only during pipeline runs.** Alternative: static deny rules in `settings.json`. Won because static rules also block development sessions from `corpus-view/` and feature-branch pushes.
- **Batches capped at ~64 KB, tokens estimated as bytes/3.** Alternative: 90 KB. Won because Read returns at most 25,000 tokens per call and number-heavy text tokenizes densely.
- **Trap detection is content-based only.** Never keyed to the 16-digit Message-ID shape that identifies the planted messages.
- **An occurrence starts at each fresh send (no `re:`/`fw:` prefix, no quoted text), not at each subject thread; a chaser must be a follow-up, never a fresh send.** Alternative: occurrence = subject thread split at 45-day gaps (the blueprint's first definition). Won because recurring same-subject sends (18 "Calpine Daily Gas Nomination" emails) would have collapsed into a few threads, dropping the most recurring process to tier C and pricing every daily send as a 100%-automatable chaser.
- **Only company staff time is priced (`priced_domains`, default `enron.com`).** Alternative: price every sender and recipient. Won because $85/h is the blended cost of the company's staff; counterparty actions are counted and shown, not priced.
- **Running notes log at `.claude/notes/NOTES-LOG.md`.** Cross-branch, organised by the brief's NOTES.md sections, so NOTES.md is assembled from records rather than memory.
