How we worked

The design came from an architect agent in a fresh context and was reviewed by Scott before any code was written; every later change of design went back through the same review. Each milestone was built by implementer agents, often several at once on disjoint files, against a shared contract written first, so no two of them touched the same file. An independent review agent read each milestone's new code before our own testing began, and every finding was fixed or answered before Scott saw the diff. Every non-obvious choice went into the decision log with what it rejected. A gold set of messages, sampled by code and labelled by hand, measured the tagging; timed rehearsals in fresh clones measured the run.

Commits were governed the same way throughout. During the day Scott reviewed each commit before it was made. For the overnight stretches he granted standing permission to commit and push feature branches, and every push to main stayed his.
